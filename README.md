# YCsys Antia-Ads v1.3.0 🛡️

**YCsys Antia-Ads** — це легке та високопродуктивне розширення для браузера, створене спеціально для блокування агресивної реклами на онлайн-кінотеатрах (Uakino, Rezka, Kinogo та ін.).

## 🚀 Основні можливості

* **Vast Killer (PRO):** Автоматична підміна рекламних XML-маніфестів (`fetch`/`XHR`) на порожні відповіді. Плеєр миттєво переходить до фільму, не очікуючи завантаження роликів.
* **Smart Skip & Speed:** Якщо реклама вбудована в потік, розширення автоматично вмикає `Mute` та розганяє відео до **16x**, миттєво прокручуючи його до кінця.
* **Deep DNR Protection:** Блокування доменів на рівні ядра браузера через API `declarativeNetRequest`. Запити до рекламних мереж (`franecki`, `getter`, `schulist` тощо) відсікаються ще до їх створення.
* **Dynamic Scanner (MutationObserver):** Інтелектуальне відстеження змін у DOM. Якщо сайт намагається вставити казино-вікно або брендування після завантаження — скрипт знаходить і видаляє його фізично.
* **Smart Pause:** Можливість поставити розширення на паузу через контекстне меню іконки. Стан синхронізується через `chrome.storage.local`.

---

## 🛠 Технологічний стек

* **Manifest V3:** Повна відповідність сучасним стандартам безпеки Chrome.
* **Service Worker:** Фоновий процес (`background.js`) для керування станом та інтерфейсом.
* **Chrome Storage API:** Енергонезалежне збереження налаштувань.
* **Vanilla JS:** Максимальна швидкість без сторонніх бібліотек.

---

## 📂 Структура проєкту

* `manifest.json` — конфігурація, дозволи та реєстрація точок входу.
* `background.js` — фоновий «мозок» розширення (меню, пауза, storage).
* `rules.json` — глобальна база доменів-паразитів (Рівень 1).
* `content.js` — інтелектуальний сканер та ін'єкції стилів (Рівень 2).
* `*.png` — набір брендованих іконок (32px – 512px) у стилі Cyberpunk Premium.

## ⚡ Встановлення (Developer Mode)

1.  Завантажте файли проєкту у папку `Antia-Ads`.
2.  Відкрийте Chrome та перейдіть за адресою: `chrome://extensions/`.
3.  Увімкніть **Developer mode** (Режим розробника) у правому верхньому куті.
4.  Натисніть **Load unpacked** (Завантажити розпаковане розширення) та виберіть папку проєкту.

## ✍️ Керування та Розробка

* **Пауза:** Натисніть праву кнопку миші на іконці розширення в панелі Chrome та виберіть «Вимкнути Antia-Ads».
* **Додавання доменів:**
    1.  Додайте ключове слово в масив `AD_KEYWORDS` у файлі `content.js`.
    2.  Додайте нове правило з унікальним `id` у `rules.json`.
* **Масштабування:** Для роботи на нових доменах оновіть масив `matches` у `manifest.json`.
